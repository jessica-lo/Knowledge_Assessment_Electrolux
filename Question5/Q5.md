On the UART side, all participants should use the same baud rate and agree on the number of data bits per frame. A parity bit could also be enabled to help detect if a bit was received incorrectly.

On top of UART, an additional protocol could be introduced to improve reliability. For example, a checksum could be included in each message so the receiver can verify whether the data was transmitted correctly. This protocol could also require the receiver to send back a response indicating whether the message was received successfully or needs to be retransmitted, similar to the acknowledgment and retransmission mechanism used by TCP.
